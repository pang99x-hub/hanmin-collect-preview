# 한민고 자료 수합 — UI 미리보기

한민고 학사운영 시스템(Hi-AX)의 **자료 수합** 기능 UI 미리보기입니다.

- **데모 데이터만** 들어 있습니다. 실제 학교 데이터·서버에 연결되지 않습니다.
- 입력한 내용은 보시는 브라우저에만(localStorage) 저장되며, 사람마다 따로 남습니다.
- 소스코드는 포함돼 있지 않습니다. 빌드 결과물만 올라가 있습니다.

## 둘러보기

| 화면 | 주소 |
| --- | --- |
| 자료 수합 홈 | `#/submissions` |
| 내가 걷는 것 | `#/submissions?tab=collecting` |
| 자료 요청 작성 | `#/submissions/new` |
| 제출 화면 | `#/submissions/demo-request-1` |

요청 작성에서 **받는 사람 → + 추가**를 누르면 조직도 · 교과별 · 저장한 그룹 세 탭으로
대상자를 고를 수 있습니다. 맨 위 **전체 선택**으로 전 교직원을 한 번에 담을 수 있습니다.

처음 상태로 되돌리려면 개발자도구 콘솔에서
`localStorage.removeItem('ax.submissions.demo.v1')` 를 실행하고 새로고침하세요.
